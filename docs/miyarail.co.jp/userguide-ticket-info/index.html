乗車券の概要

オフピー9パス 概要

  • 平日・休日の朝９時以降、当線「宇都宮ライトレール (ライトライン)」全線、「関東自動車」・「ジェイアールバス関東(※3/31まで)」の宇都宮市内の全区間、「宇都宮市地域内交通」が、購入当日に限り終電まで乗り降り自由になる一日乗車券です。2026/3/16(月)より販売開始します。

販売条件

    • 販売はご利用当日の午前9時からです。それ以前の日時での事前購入はいただけません。
    • 有効期限は当日の終電・終バスまでです。
    • 購入は、お手持ちのカードのチャージ残高・福祉ポイント・交通ポイントからの引き去りのみとなります。
    • 現金での購入はできません。カード内の残高不足の場合は、チャージしてからの購入をお願いいたします。
    • 当線 宇都宮ライトレール(ライトライン)の定期券が入ったtotraでは購入いただけません。
    • 関東自動車(バス)の定期券が入ったtotraでは購入いただけません。
    • 障がい者設定されている交通系ICカードでは購入いただけません。
    • totra・Suica・PASMO以外の交通系ICカードではご購入いただけません。(ICOCA、manacaなどは非対象です)
    • JR線や東武線は宇都宮市内でもご利用対象外です。
    • 購入後の払い戻しはできません。
    • エリア外へ乗り越した場合や、エリア外から乗車した場合は、カードをタッチした際に不足運賃を自動精算いたします。
    • バス車内・地域内交通車内で購入時、乗務員からの案内前に読み取り機へカードをタッチしますと、通常運賃が差し引かれ返金ができかねます。
    • 同じ日に他のエリアの一日乗車券を購入している場合、先に購入している一日乗車券の情報は消去され利用できなくなります。また、消去された1日乗車券の情報は復旧できません。
