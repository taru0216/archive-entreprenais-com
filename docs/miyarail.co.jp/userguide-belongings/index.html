手回り品のご案内BELONGINGS

持込み禁制品

次のいずれかに該当する物品については、車両内にお持ち込みいただけません。

  • 別表『危険品一覧表』に掲げるもの及び他の旅客に危害を及ぼすおそれのあるもの
  • 暖炉及びこん炉（乗車中に使用するおそれがないと認められるもの及び懐炉を除く。）
  • 死体
  • 動物（少数量の小鳥、小虫類、初生ひな及び魚介類で容器に入れたもの、身体障害者補助犬や盲導犬など承諾を受けた動物を除く。）
  • 不潔または臭気のため、他の旅客に迷惑をかけるおそれのあるもの
  • 車両の設備等を破損するおそれのあるもの
  • 固形長尺物で1.5メートルを超えるもの（当社が別に定めたものを除く。）
  • 刃物（他の旅客に危害を及ぼすおそれのないように梱包されたものを除く。）

無料手回り品

次のすべてに該当する物品については、2個に限り、手回り品として無料で車両内に携行してお持ち込みいただけます。

  • 3辺の和が250cm以内の物品
  • 長さ1.5メートル以内の物品
  • 1個の重量が30キログラム以内の物品

ただし、以下のいずれかに該当する犬は無料で車両内に随伴いただけます。

  • 身体障害者補助犬法（平成14年法律第49号）第16条第1項に規定する認定を受けた身体障害者補助犬。ただし、同法第12条に規定された表示を行い、お客様が身体障害者補助犬認定証を所持する場合に限ります。
  • 道路交通法（昭和35年法律第105号）第14条第1項にいう政令で定める盲導犬。ただし、当該盲導犬がハーネスをつけ、お客様が盲導犬使用者証を所持している場合に限ります。

また、お客様が身の回り品として携帯される傘・つえ・ハンドバッグ・ショルダーバッグは、当社が認めた場合は個数制限にかかわらず、車両内にお持ち込みいただけます。

特殊手回り品

持ち込み規制品に規定する制限を超える物品であっても、次のいずれかに該当するものは、当社の承諾を受け、車両内が混雑していない場合に限りお持ち込みいただけます。

  • 自転車は、解体もしくは折りたたんで専用の袋に収納し携帯可能なもの
  • サーフボード等の運動用具、つり道具は、専用の袋またはケースに露出なく収納し、車両の設備等に対して損傷がないよう配慮されたもの
  • 沿線自治体の施策等に当社が協力し、車両への持ち込みを認めたもの

また、小犬、猫、鳥類またはこれに類する小動物（猛獣、ヘビ類を除く。）については、動物専用の容器に収納し、かつ他のお客様に迷惑をかけるおそれがないと認められるものに限り車両内にお持ち込みいただけます。
